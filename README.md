# Customer Churn Data Cleaning

Customer churn raw dataset cleaned using Python (pandas).

## Files
- customer_churn_raw.csv - original data
- Data_cleaning.ipynb - cleaning code
- customer_churn_cleaned.csv - cleaned data

## Cleaning steps
- Removed 5 duplicate rows
- Converted TotalCharges to numeric and filled missing values
- Corrected 7 monthly charge outliers
- Filled missing Region with "Unknown"
